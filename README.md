# Omni Toolkit – The Ultimate Termux Arsenal

[![License](https://img.shields.io/badge/license-MIT-blue)](LICENSE)
[![Version](https://img.shields.io/badge/version-2.0-brightgreen)]()

Omni is an all‑in‑one reconnaissance, forensics, automation, and payload toolkit designed for Termux. It combines 30+ tools into a single interactive menu and standalone scripts – all with a unified theme system that colors your terminal, font, prompt, and Omni’s own menus.

## Features
- **Reconnaissance** – subdomain brute‑force, port scan, DNS, WHOIS
- **Web Crawler** – extract links and emails from any URL
- **Network Scanner** – ARP sweep, ping sweep, local netstat
- **Forensics** – file hashing, entropy, EXIF read/write, metadata scrubber
- **Steganography** – LSB hide, append payload, JPEG+ZIP polyglot
- **Payload Generator** – reverse shells (Python, Bash, PowerShell)
- **OSINT** – email breach checker, fake identity generator, social engineering templates
- **Automation** – task scheduler, mass scan, webhook notifiers
- **Unified Themes** – change Termux colors, font, zsh prompt, and Omni menus together

## Installation
```bash
git clone https://github.com/idontevenknown/Omni.git
cd Omni
chmod +x install.sh
./install.sh
```
